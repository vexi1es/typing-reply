# Просто напиши

Личная версия [lgordey/typing-reply](https://github.com/lgordey/typing-reply) (MIT): ответ на голосовое видео, где руки медленно
печатают текст на телефоне. Всё считается на телефоне, сервера нет. Это PWA, которая после первого открытия работает офлайн.

Что изменено по сравнению с оригиналом:
- вертикальное видео 720×1280, в кадре весь телефон и шапка чата с именем и фото собеседника;
- вид чата: Telegram или iMessage; длину голосового можно задать (3 с – 10 мин);
- языки: русский и узбекский (раскладка с ʻ для oʻ/gʻ);
- нет водяного знака, финальной заставки, аналитики и Worker;
- service worker (`sw.js` генерирует `vite.config.ts`) кэширует всё приложение.

## Команды

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ + sw.js
npm run preview      # проверить сборку и офлайн-кэш
npm test
npm run frames -- "Текст" ru normal 0.5,3,end telegram "Имя" [фото.jpg] [сек_голосового]
npm run icons        # public/icon-*.png и apple-touch-icon.png
```

## Хостинг

Cloudflare Pages: команда сборки `npm run build`, папка `dist`. В `public/_headers` для `sw.js` выключен кэш,
чтобы обновления доходили до телефона.

На iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“». После этого всё работает без интернета.
Нужен iOS 16.4+ (H.264 через WebCodecs).
